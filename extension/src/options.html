dsh-insight 设置

连接

运行中的 dsh web 地址。浏览器桥接连接到 ws://该主机/dsh-insight/bridge，「dsh 界面」按钮从该地址嵌入完整界面。

划词解读

在网页上选中文字后旁边那个小按钮上的字。自动解读模式下用不到。

自动模式在停手约 0.45 秒后发请求，同一段文字只解读一次。「只进侧边栏」 会关掉页面里的浮窗，结果只在扩展侧栏显示；侧栏没打开时这两种模式不会发起 解读，也不弹浮标 —— 没有地方显示结果，就不白跑一次模型。改完点「保存」生效。

固定在右下角后，浮标与浮窗都钉在同一处，读长文时不会随选区乱跑。

决定「解读」到底是什么意思。内置口径也可以直接改：保存后会记成你自己的一份 （下拉里标「已修改」），host 那边的原文不动，随时能撤销。

只有自定义口径需要名字；选到内置口径时这一项是灰的。

外观

只影响「划词解读」面板。正文、代码块与边框会按底色的深浅自动配色 （浅底配深字、深底配浅字），不用自己调一堆颜色。改动即时生效。

代码块与标题按比例一起缩放。改动即时生效。

预览：加粗、斜体、行内代码。

def get_weather(city: str) -> str:
    return f"It's always sunny in {city}!"
